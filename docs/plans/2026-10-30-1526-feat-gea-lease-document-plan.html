Goal Capsule

Objective: a renter of a Grants-managed property receives a lease that reads as a Grants document (cover page, branded pages, clean schedule layout) and is a valid current Victorian residential rental agreement whose every value comes from a real record.

Means: render the lease as HTML laid out to PDF by PyMuPDF, with the Form 1 v009 text checked by a compliance test (KTD1, KTD2).

Authority: the official Form 1 text (Regulations v009, Sch 1) > Requirements (R-IDs) > Key Technical Decisions > unit Approach.

Stop conditions: stop and report if the v009 Form 1 text cannot be obtained verbatim; if PyMuPDF cannot place the renter signature labels or a page X of Y footer; or if any requirement would need data that has no real source.

Execution profile: Standard depth, test-first (CLAUDE.md coding discipline). Claude Code builds; Stuart approves the visual result and any push to main.

Summary

Replace the plain CAV Form 1 Word template with GEA's own lease document: a cover page and running header and footer modelled on the GEA iAgree agreement, Studio Minimalist typography, and "label | value" schedule rows, while every Part, item and prescribed sentence of the current Form 1 stays in place and in order.

Problem Frame

formsAI produces CAV's own grey-boxed Form 1. It does not look like a Grants document, and on 30 Oct 2026 a draft went out with the fixture's invented landlord, which shook trust in the output. Grants' earlier iAgree agreements had a clean branded layout, but they predate the 2021 regime and their structure cannot be reused. Form 1 has also been amended since 2021 (S.R. 123/2025), so the current template may carry outdated wording.

Planning Contract

Key Technical Decisions

KTD1. Render with PyMuPDF's fitz.Story (HTML and a CSS subset to PDF). It is already installed (1.28.0) and needs no Dockerfile change, unlike headless Chrome. Layout uses block flow and tables only, because Story has no flexbox or grid.

KTD2. The v009 Form 1 text is the reference, held as a test fixture. Extract Schedule 1 Form 1 from the authorised Regulations v009 PDF into forms_fill/tests/fixtures/form1_v009.txt. A test normalises whitespace and asserts every reference line appears, in order, in the rendered PDF text. Cross-check against CAV's current Word Form 1.

KTD3. A Python document builder, not a template engine. A lease module assembles the HTML from the context with html.escape, so selector logic (fixed or periodic term, rent period) is ordinary code and no Jinja dependency is added.

KTD4. Page chrome is stamped after layout. Story lays out the body; a second pass draws the header, footer and "Page X of Y" on every page except the cover, once the page count is known.

KTD5. Vendor the brand assets. Inter TTF (OFL) and a black-and-white logo PNG ship inside the package; pyproject.toml package-data is extended so the Railway image carries them.

KTD6. Keep the signing anchors literal. The renter signature rows print "Signature of renter N" with a "Date" label within 70pt below and clear space to the right, so forms_fill/sign_pdf.py placement is unchanged. Only its signing-record page is restyled. Its footer reads "Signing record", outside the X of Y count.

KTD7. A new html engine in render.py. It returns (None, pdf_path, warnings) like the overlay engine, so core.py, FillResult and the API stay as they are (R9).

High-Level Technical Design

The flow: fill_form builds the context from real data; the lease builder turns Form 1 plus that context into HTML; Story lays it out; the chrome pass adds header, footer and page numbers; the PDF then follows the existing approve-send and signing path unchanged.

Risks · Appendix

Risks & Dependencies

Risk · legal

A re-typeset Form 1 could be challenged as not "in the prescribed form". Mitigation: verbatim text, prescribed order, Part E only for extras, and the compliance test; s 53 "like effect" applies.

Risk · renderer limits

Story's CSS subset may not reproduce the example exactly. Mitigation: block-and-table layout only; the stop condition triggers a renderer review rather than a compromised design.

Risk · signing anchors

Renaming or wrapping "Signature of renter N" breaks stamping. Mitigation: KTD6 plus the U4 end-to-end test.

Dependency

Real data needs FORMS_DATA_PROVIDER=propertyme, now set on the local forms-api; Railway still runs the fixture and will refuse real tenancies until given a real provider.
